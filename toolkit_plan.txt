PYTHON TOOLKIT PLAN

TOOLS
1. Number Guessing Game: The computer chooses a number from 1 to 10 and gives higher-or-lower hints until the player guesses it or returns to the menu.
   Concepts: loop, random number, conditionals, input validation, f-strings.
2. To-Do List: The user can view, add, and remove tasks in a list that stays available while the program runs.
   Concepts: changing list, loop, conditionals, enumerate, input validation, f-strings.
3. Simple Calculator: The user enters two numbers and chooses addition, subtraction, multiplication, or division.
   Concepts: conditionals, arithmetic, input validation, f-strings.
